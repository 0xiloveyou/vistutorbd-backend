1. THE ENGINE RULES
==============================================================================

1.1  ONE SOURCE OF TRUTH, THREE STYLES
  Write each activity once as a list of STEPS. Each step holds:
      target : the element on screen it talks about (CSS selector or id)
      say    : short spoken/bubble sentence (EN + BN)
      draw   : what to animate in line art (stroke, arrow, highlight)
      text   : the plain written explanation (can be longer)
  Then the Style button only changes HOW the same steps are shown:

   Style button        What the student sees
   ------------------  -----------------------------------------------------
   Robot explains      Robot flies to the target, points, talks in a bubble,
                       reacts happy/sad/thinking. Voice on if sound is on.
   Line art            No character. Same steps drawn as animated strokes,
                       arrows, brackets, hatching. One short caption.
   Text only           Calm numbered written steps. Good for exams, slow
                       devices, screen readers, and older students.

1.2  WHEN THE ROBOT SHOULD APPEAR  (your rule: "robot if necessary, else not")
  USE the robot when:
    - the student is young (Play, Class 1-3): robot is the main guide
    - a multi-step method is being shown ("Show me how")
    - something must be pointed at on a busy screen
    - the student presses "I didn't understand" (robot slows down, new wording)
    - a short celebration or gentle "try again" is needed
  DO NOT use the robot when:
    - the game is timed or is a quiz/test mode
    - the canvas is dense (graphs, geometry constructions, matrices) and the
      robot would cover the work. Use Line art or a small corner robot instead.
    - the student is Class 9-12 and chose Text only / Line art
    - the same hint was already shown twice (stop repeating)

1.3  DEFAULT STYLE PER CATEGORY
   Category      Default       Robot behaviour
   -----------   -----------   ------------------------------------------------
   Play&Nursery  Robot         Always on, voice first, almost no reading
   Class 1-5     Robot         On; talks short; can be muted
   Class 6-8     Line art      Robot only on "Show me how" / confusion
   Class 9-10    Line art      Small corner robot, optional
   Class 11-12   Text only     Robot hidden by default; "Explain" button opt-in

1.4  FOUR BUTTONS EVERY ACTIVITY SHOULD HAVE (already in your game)
   Check | Show me how | Suggestion (hint) | I didn't understand
  Rule for "I didn't understand": do NOT repeat the same sentence. Switch the
  representation (picture -> numbers -> words) or shrink the step.

1.5  FEEDBACK RULES (all ages)
   - Never say "wrong". Say what is true: "That makes 5/8. We need 3/4."
   - First wrong: encourage. Second wrong: hint. Third: show the method.
   - Score is for fun (stars); never block progress for young classes.
   - Reduced-motion: if the device asks, skip the flying and show instantly.

2. FOURTEEN REUSABLE INTERACTION TEMPLATES
==============================================================================
Build each one ONCE as a component, then feed it different content per class.

T01  DRAG-TO-BUILD
     Student drags blocks/pieces into a frame to make a target amount.
     Used for: counting, place value, fractions, area tiles, equations.
     Check: sum of placed pieces equals target.

T02  SLIDER EXPLORER
     One or more sliders change a picture or graph live. A readout shows the
     numbers. Prompt: "Move it. What stays the same? What changes?"
     Check: optional mini-question after exploring ("Make the slope 3").

T03  COMPARE THREE REPRESENTATIONS
     Same idea shown as picture, table, graph, words. Student matches or ranks.
     Check: matches and ranking correct.

T04  PREDICT, THEN RUN
     Student commits to a guess, presses Run, an animation reveals the truth,
     then the screen shows the gap between guess and result.
     Used for: races, probability, rates, motion.

T05  TAP-TO-SORT / SORTING BINS
     Items fall; student drags into bins (even/odd, shape type, prime/not).
     Check: all items binned. Reveal rule at end.

T06  NUMBER LINE HOP
     A character hops along a line. Student sets jump size and count.
     Used for: addition, subtraction, integers, multiplication, fractions.

T07  BALANCE SCALE
     Two pans with objects/unknown boxes. Student adds/removes the SAME thing
     from both sides. Used for: equal sign, equations, inequalities.

T08  DRAW-IT-YOURSELF (trace / plot)
     Student traces a shape, plots points, or draws a line through points.
     Check: tolerance-based (within X pixels). Line art style shines here.

T09  FIND-THE-MISTAKE
     A worked solution with one wrong line. Student taps the bad line.
     Check: correct line chosen; then explains why in a choice list.

T10  CONSTRUCT & MEASURE
     Student drags vertices/points; app shows angles, lengths, area live.
     Check: "Make a triangle with area 12" within tolerance.

T11  DATA PLAYGROUND
     Student drags dots on a dot plot / bars on a chart. Mean, median, spread
     update live. Used for: statistics from Class 3 to Class 12.

T12  SIMULATE MANY TIMES
     Button "Run 1 / 10 / 100 / 1000 times" shows results piling up as a graph.
     Used for: probability, randomness, distributions.

T13  STORY PROBLEM WITH A PICTURE ENGINE
     A short local story (bazar, school bus, river, cricket) generated from a
     template with random numbers, solved with a built-in tool.
     Check: numeric input with accepted tolerance or unit handling.

T14  BUILD-A-GRAPH-FROM-A-STORY
     Student sets a graph's shape to match a story, or writes the story that
     matches a graph (two directions). Used for: rates, functions, calculus.

3. YOUR TWO LINKS, REBUILT AS ORIGINAL ACTIVITIES (FULL SPEC)
==============================================================================

What the first link teaches (pattern only): compare rates when each is given in
a DIFFERENT form (not all as the same kind of data), then decide who wins.
What the second link teaches (pattern only): compare two data sets by looking
at the centre AND the spread, and say how far apart the centres are in units of
the spread.

------------------------------------------------------------------------------
EXAMPLE A:  "RIVER BOAT RACE"            (Class 6-8, pattern T03 + T04)
------------------------------------------------------------------------------
Idea     Three boats race across a river. Each boat's speed is given in a
         different form. Students find each unit rate, rank the boats, and
         then watch the race to see if they were right.
Screen   Three cards, one per boat.
           Boat Lal    : a distance-time GRAPH (a straight line)
           Boat Nil    : a TABLE  (time 2,4,6,8 s -> distance 9,18,27,36 m)
           Boat Sobuj  : a SENTENCE "goes 28 m in 6 seconds"
         Below: a river lane view, finish line at 60 m.
Student  1. Fills in "metres per second" for each boat (input boxes).
         2. Drags the boats into 1st / 2nd / 3rd.
         3. Presses Race. Boats move at constant speed. Rank is confirmed.
Numbers  Lal 4.8 m/s, Nil 4.5 m/s, Sobuj 4.67 m/s. Close on purpose so
         students must really calculate. Randomise within a safe range.
Check    Unit rates within 0.05; ranking matches rates.
Robot    Flies to each card, "Let's turn this into metres in ONE second."
         Points at two table rows, draws the division. Celebrates after race.
Line art Slope triangles are drawn on Lal's graph; table rows get rise/run
         brackets; the sentence is underlined and divided.
Text     "Step 1: Pick two points. Step 2: change in distance / change in time."
Extra    "Challenge": boat with a head start (graph does not begin at 0).
Why it works: the student has to see that graph, table and words are ONE idea.

------------------------------------------------------------------------------
EXAMPLE B:  "TWO DISTRICTS, ONE MONSOON"   (Class 8-9, pattern T11 + T03)
------------------------------------------------------------------------------
Idea     Rainfall (mm) over 10 days in two districts shown as dot plots.
         Which district is "more rainy" and which is "more unpredictable"?
Screen   Two dot plots stacked on one shared axis. Markers for mean appear
         when the student taps "Show mean".
Student  1. Taps to show each mean. 2. Taps "Show spread": a bar for each dot's
            distance from the mean appears (this builds mean absolute deviation).
         3. Reads off MAD for each district (enter numbers).
         4. Answers: "The difference between the means is ___ times the MAD."
Data     Barguna: 12,14,15,15,16,17,18,18,19,20  (mean 16.4)
         Sylhet : 5,9,13,16,19,22,25,28,30,31    (mean 19.8)
         Randomise from templates so the cohort gets different sets.
Check    Mean exact; MAD within 0.1; ratio within 0.1.
Robot    Walks along the dots, "each dot is this far from the mean", then drops
         the bars. Says "wide spread means less predictable".
Line art Dashed distance lines from every dot to the mean, shaded totals.
Text     Short worked table: value | distance | distance total | divide by 10.
Extra    Drag a dot: watch mean and MAD update live (pure exploration).

------------------------------------------------------------------------------
EXAMPLE C:  "COUNT THE MANGOES"        (Play & Nursery, pattern T01)
------------------------------------------------------------------------------
Screen   A big mango tree and an empty basket. Big number tile "3".
Student  Taps or drags exactly 3 mangoes into the basket. Each mango makes a
         "pop" and the robot counts aloud "one... two... three!".
Check    Basket count equals the number; too few: "One more!" Too many: robot
         gives one back to the tree.
Robot    Always on, voice only, no text needed. Big finger-sized targets.
Line art Mangoes appear as thick outlines the child traces, then fill with color.
Text     Not offered for this age (just numbers and pictures).
Rounds   Numbers 1-5 first, then 6-10. Never time-limited.

------------------------------------------------------------------------------
EXAMPLE D:  "SLOPE OF THE HILL"        (Class 11-12, pattern T02 + T14)
------------------------------------------------------------------------------
Screen   A curve (e.g. y = x^2 - 2x) and a point A on it. A second point B on
         the curve slides toward A. A secant line is drawn through A and B.
Student  1. Drags B closer and closer to A (slider "h").
         2. Table fills: h, slope of secant. Watches values approach a number.
         3. Presses "Make tangent": the line settles on the tangent at A.
         4. Types the limit value and the derivative formula guess.
Check    Slope within 0.05 of f'(a). Then asks: "Where is the tangent flat?"
Robot    Hidden by default; "Explain" opens a small corner robot.
Line art Secant lines fade into the tangent while h -> 0, with a zoom-in lens.
Text     Difference quotient written step by step with limit notation.
